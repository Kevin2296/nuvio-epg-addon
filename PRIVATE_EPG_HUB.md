# Private EPG Hub (native Nuvio extension)

Open Settings → Live TV → Setup → Playlists / TV Guides (EPG) → Private EPG Hub.
Choose a country to add its public EPGShare01 feed. No feed is enabled by default. Clicking an existing country does not create duplicates; a disabled source is enabled again. Source rows below the hub provide edit, disable, update and removal. Use the existing update interval setting for automatic guide refresh while Nuvio runs, and startup refresh after reopening. This does not install a background Android worker.

The hub shows how many imported channels have a programme now, only upcoming programmes, or no upcoming guide. These counts cover the repository's imported channels, including hidden channels, and all sources (also provider guides). They are not just the public hub feeds. An expired or malformed interval does not count as coverage. Counts refresh on data changes and every minute while the settings screen is observed.

Existing XMLTV parsing, cached database, automatic matching and manual Change EPG assignment remain in use. This first native version adds source selection and aggregate diagnostics; it does not replace the existing matching engine or provide a new country-scoped matcher. Review regional and timeshift matches in the guide. Adult/XXX sources remain manual via Add EPG Source; the hub does not bypass existing parental controls or promise adult coverage.

Public download presets: NL1, BE2, DE1, PL1, US2, UK1, verified in the publisher directory on 2026-11-03. https://epgshare01.online/epgshare01/ . All six returned HTTP 200 and gzip magic bytes in a GET probe using Nuvio's existing User-Agent. HEAD requests without that User-Agent returned 403; reachability checks should use the actual download method. Full feed contents and TV-device compatibility were not validated by that header probe. Availability and coverage are external and may change; directory presence does not certify programme accuracy or redistribution rights. Do not rehost these guides by default.

Privacy: this feature makes ordinary guide downloads only. It does not upload channel inventories, stream URLs or Xtream credentials. The public guide server sees the device's IP address. Country presets use a separate OkHttp client with platform certificate checks, redirects disabled and a 32 MiB compressed download limit. EPG network errors stored/reported by this path are generic, because exception text can contain URLs. Existing provider handling is otherwise preserved. Source settings continue to use the app's existing persistence/sync behavior; this extension does not add any external account or change existing sync preferences.

No TrueNAS, Nextcloud, GitHub account, NAS endpoint or separately installed addon manifest is required. This is compiled into the customized Nuvio APK. The standalone epg-hub prototype in the parent workspace is independent.

Validation: `:app:testFullDebugUnitTest --tests com.nuvio.tv.livetv.data.PrivateEpgHubTest --tests com.nuvio.tv.privatehub.PrivateHubTest` and `:app:assembleFullDebug`. Device UI/navigation and actual guide downloads still need a TV smoke test. Use the local project's existing private signing configuration; never publish private signing keys, provider sources, logs or local.properties.
